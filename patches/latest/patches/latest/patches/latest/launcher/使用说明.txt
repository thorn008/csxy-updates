创世西游 · 单机启动器

完整解压后，双击 CSXY启动器.exe 或 一键启动.bat，点击“一键开玩”。
等游戏窗口打开后再关闭启动器；关闭启动器不会停止游戏或服务。
使用自己的账号名和任意测试密码，创建角色即可游玩，每台电脑独立存档。

协议抓包开关
默认关闭。排查问题时可开启，更新后的服务运行中约一秒内生效。
抓包保存在 server/evidence；关闭开关会停止新记录，已有文件保留。
从旧版更新后，请先退出游戏并停止旧服务，再用新启动器重新开玩一次。

角色存档 / GM 工具
先退出游戏，点击“停止服务端”，再打开“GM 工具”。
用下拉框选择角色，其他字段直接输入整数；等级限 1～130，超过上限会被拦截。
可修改经验、金钱、绑定金钱、元宝、赠送元宝、通宝和商城积分。
点击“备份并保存”，下次进入游戏生效；等级变化会同步生命、法力和可用潜能。
等级不能降低到已有加点所需的等级以下；任务、物品和身份数据保持不变。
每次保存前自动备份到 server/state/gm_backups；不会覆盖其他角色。
如提示存档已变化，点击“重新读取”再编辑。

存档目录按钮打开 server/state。请保留整个目录，更新时不要覆盖自己的存档。
角色存档主文件为 characters.json，旁边的 .bak 用于自动恢复。
需要回退 GM 修改时，先退出游戏和服务，把选中的 gm_backups 文件复制为
characters.json 以及 characters.json.bak；不确定时请先保留当前文件。

服务日志用于排查启动问题；怪物编辑仍为预留入口。
同一台电脑无法同时运行本机开发服和分发包服务，请使用服务对应目录的启动器。
完整分发包包含 Python；如缺少 DirectX 组件，可安装 game/directx 中的组件。


启动器 V1.1 / 更新中心
旧启动器仍可正常开玩，只是没有更新中心。
右上角“更新中心”可选择本地补丁文件夹，先检查，再安装。
安装前退出游戏并停止服务端；安装成功后重新打开整个启动器。
原程序自动备份在 updates/backups；失败自动恢复，存档与设置保留。
已预置 thorn008/csxy-updates 的 GitHub 更新地址，点击检查即可。
可填写自己的 HTTPS 清单地址；已有自定义设置保留。
未配置地址时不联网，不会强制更新。补丁须按版本顺序安装。
第一次升级可关闭启动器后，将补丁里的内容复制到 CSXY启动器.exe
所在目录并覆盖；不要把整个补丁目录作为子目录。

商城消耗品修复
大化血丹、浊气丹、元气丹、魔气丹增加命源；对应神丹增加法源。
命源与法源储存后，在战斗结束时补充角色与本场参战召唤兽的生命、法力。
高阶丹药保留原等级要求，容量不足时不扣物品。
彩粉盒、传音符盒子、五洲神行盒、副本钥匙链、超级棉花糖包、四圣石盒
可按说明数量开包；开包不代表对应衣橱、宠物培养等系统已经恢复。

端口占用 / 一键清理
服务端卡片下方点“一键清理”，列出 TCP 8000、20560、28000 及 UDP 20560、28000 的占用进程。
退出游戏后，点击“结束占用进程”，释放端口；再返回首页一键开玩。
可能是另一份本地服或其他软件占用，按钮会强制结束列出的进程。
权限不足时可点击“以管理员重开”；系统保留进程无法清理。
