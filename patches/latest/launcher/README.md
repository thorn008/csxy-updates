# 创世西游单机启动器

完整解压后双击根目录 `CSXY启动器.exe`（或 `一键启动.bat`），点击“一键开玩”。本地服务就绪后自动打开游戏。朋友使用自己的账号名和任意测试密码，在游戏内创建角色；每台电脑独立存档。

当前启动器 **V1.1**。右上角“更新中心”支持本地补丁安装、HTTPS/GitHub 清单检查与下载；未配置地址时不联网。旧启动器仍可正常使用。补丁默认导出未压缩目录，后续运行 `BUILD_PATCH.ps1` 只导出上次发布后改变的文件。详见 [更新发布说明](更新发布说明.md)。

## 当前功能

- 深蓝紫圆角控制台、自绘标题栏、侧边工具导航、彩色启动卡片和紧凑抓包开关。
- 一键开玩、单独启动游戏/服务、停止本目录已识别的服务；关闭启动器不停止服务。
- 传递原客户端所需的窗口句柄，跳过旧登录器提示。
- 抓包默认关闭；开关写入 `launcher.json` 的 `captureEnabled`，服务约一秒内读取生效。
- 抓包开启时写入 `server/evidence`；关闭后保留旧文件，网络回复和普通错误日志继续工作。
- 打开存档目录 `server/state` 和服务日志；使用说明在同色圆角窗口内阅读，采用自绘紫色滚动条。
- 基础 GM：深色圆角角色下拉选择；等级、经验、金钱、绑定金钱、元宝、赠送元宝、通宝及商城积分采用普通数字输入框。等级键入及粘贴限制为 1～130，保存再校验。
- GM 保存仅允许游戏和服务退出后进行；自动备份、校验和、原子写入、过期快照与跨进程锁保护。
- 等级限 1～130，金额与经验限非负 32 位有符号整数，商城积分限 0～65535。降级不能低于已分配潜能所需等级。
- 等级改变同步生命/法力和潜能；任务、物品、外观及其他角色保留。
- 怪物编辑仍为预留入口。

从旧版更新后需要退出游戏并停止旧服务，重新打开新启动器启动服务一次。之后抓包开关可在运行中切换。GM 备份保存于 `server/state/gm_backups`，重新读取可刷新角色列表。

## 分发

`build_package.py` 构建独立 Python/Crypto 运行环境和游戏资源，默认只生成未压缩目录，可按需自行压缩，并生成新的分发专用密钥，不读取或复制开发者私钥。分发包不含个人角色存档、会话、缓存、抓包、日志和备份。更新时保留自己的整个 `server/state`。

`refresh_package.py` 为已用于测试的分发目录同步程序文件并保留存档；同时从之前验证的干净 ZIP 提取一份新版未压缩目录，供发给朋友使用。不会创建 ZIP，也不会将测试角色、缓存或日志放入新目录；保留原分发专用密钥。

## 验证与后续

PowerShell 脚本使用 UTF-8 BOM，兼容 Windows PowerShell。离屏生成界面预览；GM 保存与抓包切换在临时文件和模拟对象上验证。实际游戏运行由用户验收。此版默认本机单机，不提供外网联机或账号自动登录。
